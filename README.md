# Midnight Racers — Neon Muscle: Street Rivals

An original browser-based arcade street racing prototype inspired by the energy of late-night American street racing games — without copying any specific game, vehicle, logo, character, or asset.

## Play

- **W / Up Arrow** — Accelerate
- **S / Down Arrow** — Brake
- **A / D or Left / Right** — Steer
- **Shift** — Nitro
- Touch controls are included for mobile.

## Features

- Four fictional American performance cars with distinct driving stats
- Night city / neon highway visual system rendered entirely in Canvas 2D
- Rival racers and collision logic
- Nitro boost and procedural exhaust effects
- Position, speed, distance, top-speed and race-time HUD
- Responsive desktop + mobile controls
- Procedural WebAudio engine tone
- Zero image assets required

## GitHub Pages

This is a static HTML/CSS/JS project and can be published directly from the repository root.

## Originality

The project uses original names, UI, car silhouettes, and programmatic visuals. It aims for the genre feeling of fast midnight street racing rather than reproducing copyrighted assets from any existing title.
